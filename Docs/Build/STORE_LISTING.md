# Листинг для магазинов

## Yandex Games

- **Название**: Deep Lone — Ядро Коры-7
- **Краткое описание (60 симв.)**: Бури на 1000м, сражайся с безумием, найди ядро!
- **Полное описание**:
> Ты — дроид LONE-1, последний на заброшенной шахте Кора-7. Бури сквозь 6 слоёв: от ржавых пустошей до заражения. Топливо и перегрев решают судьбу, а с 500м начинается безумие — фейк-руды, галлюцинации, шёпоты. Собирай 5 артефактов, качай бур MK3 и выбери финал: жертва или побег. Один заход 5-15 мин — идеал для «ещё одну попытку».

- **Жанр**: Аркада → Шахта/Рогалик
- **Управление**: WASD + мышь/тач
- **Иконка**: `icon_512.png` 512×512 PNG
- **Обложка**: `promo_banner.png` 1280×720
- **Скриншоты**: 3-5 из Run (глубина, враги, магазин)
- **Теги**: drilling, roguelike, pixel, sci-fi
